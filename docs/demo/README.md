# デモ動画

`astera_demo.mp4`: Astera のデモ＆紹介動画。1分58秒、1920×1080、30fps、無音、日本語の字幕つき。

## 内容（順番）

1. タイトル
2. 見たい天体を選ぶ（月）
3. 東京23区を 3D で見わたす（PLATEAU）
4. おすすめ地点の自動判定（SHIBUYA SKY）
5. 建物に遮られないかの計算（緑の線＝見える）
6. 展望台の目線で空を見上げる
7. 時刻スライダーで空が動く
8. 判定の理由（遮蔽・雲量・暗さ・光害）
9. 地上の地点では建物の裏（赤い線）
10. 地上の目線で確かめる
11. 高さで比べる（地上 5 m と展望台 204 m）
12. 出典と GitHub のリンク

## 撮り方

- iOS シミュレータ（iPhone 17 Pro）で `xcrun simctl io <UDID> recordVideo --codec h264 --force raw.mp4` を回しながらアプリを操作した
- 冒頭（天体の選択〜3D 表示）は 10/26 21:00、それ以降は 2026-10-29 20:00〜21:15 に日時を合わせて撮っている。地上の地点は「汐留 地上（デモ用）」
- 録画は可変フレームレートなので、`ffmpeg -vf "setpts=N/50/TB,fps=30"` で 30fps に直してから切り出した
- 背景・端末の枠・字幕・タイトルは Pillow で PNG を作り、ffmpeg の `overlay`（`enable='between(t,…)'`）で重ねた。字幕の文言や切り出し区間を変えるときは、画像を作り直して同じ手順で組み立てる
