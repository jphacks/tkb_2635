# 8-15 日時と選択済み天体のヘッダー

添付の宇宙の雰囲気を基に、左に日時・天体名、右上に枠のない天体を配置。
既存の星空背景とガラスの日時ボタンを使い、地図・おすすめ／要確認タブ・一覧は変更しない。
ホーム上部の天体ドロップダウンを外し、天体の選び直しは既存の戻る操作から行う。

## 選択結果の引き継ぎ

- 既存の `CabinPortrait` を使い、月面・NASAの惑星画像・恒星・星座絵をそのまま表示する。
- 確認画面で確定したときに、従来の `model.target` と表示用の `selectedCabinTargetID` を保存する。
- 星座の計算対象は代表星のため、表示用IDで「選んだ星座」と「同じ代表星の単独選択」を区別する。
- 他画面で対象が変わった場合は、表示用IDと観測対象の一致を確認し、不一致なら現在の観測対象の絵へ切り替える。
- 星座の代表星に関する既存の注意・画像の出典を表示。新たな選択UIは設けない。
- 方角・高度は観測地点によって変わるため、参考画像の固定値は追加しない。

## 日時の編集

- 上部の日時ボタン（48pt以上、下向き矢印付き）で日付・時刻の編集シートを開く。
- 開くたびに現在の `model.date` を下書きへコピー。「適用」で `model.date` を更新。
- キャンセルやシートのスワイプ閉じでは、観測日時を変更しない。
- 表示とDatePickerは日本時間で統一し、年・日本時間の表示、VoiceOverの年月日時刻を付ける。
- 既存の日時変更に伴う推薦・地図・予報範囲の更新を利用する。

## レイアウトと検証

左右は別の領域で配置し、天体にはクリップ・四角い背景・選択ボタンを付けない。
狭い一覧幅（280pt未満）やアクセシビリティ文字サイズでは、天体を右寄せした上段、日時・天体名を下段に配置。
日時は縮小でき、天体名と注意書きは高さ方向に折り返す。

静的確認：地図とタブの呼び出しを含むSpotResultsViewが不変、確定時の表示用ID追加のみ、既存の天体描画を変更していないこと。
Windows環境にSwift/Xcodeがないため、ビルド・シミュレータ描画・実機操作は未確認。

macOSで `swift test`（Packages/StarCore）、`xcodebuild -scheme StarSpot -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build` を実行し、次を確認する。

- 月→土星→恒星→星座の順に既存選択画面から確定し、名前・絵・観測対象が一致する。
- 星座と同じ代表星の単独選択が別の絵になり、土星の環が切れない。
- 日付・時刻・年を変更して適用、再度開く、キャンセル、スワイプで閉じる。翌日0時前後も日本時間で一致する。
- 320/375/390ptと大きな文字で天体が日時や名前に重ならない。
- 地図・タブ・件数・絞り込み・詳細への遷移と、天体の選び直しが維持される。
