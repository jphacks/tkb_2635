# ホーム画面の設計方針（h）

Claude の frontend-design スキルで方針を決めた。テーマは「観測手帳を夜空に開いたような、静かなダーク画面」。

- **背景は夜空**: 黒に近い紺から藍へのグラデーションに、ごく薄い星を散らす。詳細画面（全画面 3D ＋シート）と同じ暗さにそろえ、画面を移っても目が慣れたままにする
- **情報の順番は「条件 → 地図 → 一覧」**: まず「今夜 21:00 の 月」と大きく出し、何の結果を見ているかを一目で分かるようにする。日時・天体・月の情報は 1 枚のカードにまとめる
- **地図は大きく、スクロールとぶつけない**: `List` をやめて `ScrollView` に組み替え、地図の高さを画面幅に応じて 260〜320pt にした。指で動かしやすいよう、右上のボタンで全画面の地図も開ける（ピンから詳細へ行ける）
- **色は段階の色だけ**: 推薦＝緑、要確認＝橙、見えない＝赤、利用不可＝灰。見出し・行の左の細い線・点数バッジ・ピンを同じ色にして、色の意味を 1 つに保つ。ほかの強い色は、見出しの天体名の淡い月色だけ
- **行は上から下へ一度で読める並び**: 点数バッジ → 地点名 → 距離 → 理由 1 行。種類・区・目の高さは小さく最後に置く
- **数字は等幅**: 点数・時刻は等幅数字にして、並べたときに桁がそろうようにする
- 「スコアは観測条件の目安で、観測できる確率ではありません」は条件カードの下に必ず残す（誤解を防ぐため）
- VoiceOver では、条件カード → 地図 → 段階の見出し → 各行の順に読まれるようにし、見出しには見出しの印を付ける
