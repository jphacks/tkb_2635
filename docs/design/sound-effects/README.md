# Astera 効果音

添付された全体 BGM のメタデータと効果音仕様を確認し、ガラスベル、柔らかなシンセ、控えめな空気音で7種類を制作しました。効果音は外部ライブラリなしで再生成でき、素材は `App/Resources/Audio/SE/` にあります。

| ファイル | 使用場面 | 長さ | 再生側の音量目安 |
|---|---|---:|---:|
| `01_app_start.wav` | アプリ起動 | 1.50秒 | 45% |
| `02_map_open.wav` | 3Dマップを開く | 1.20秒 | 40% |
| `03_pin_tap.wav` | 地図のピンタップ | 0.30秒 | 35% |
| `04_celestial_select.wav` | 星・月を選択 | 0.60秒 | 40% |
| `05_time_tick.wav` | 時刻スライダー | 0.12秒 | 15% |
| `06_location_found.wav` | 観測できる地点を発見 | 1.40秒 | 50% |
| `07_view_move.wav` | 3Dの回転・拡大 | 0.25秒 | 15% |

全ファイルは44.1 kHz・ステレオ・16 bit PCM WAVで、ピークを約 −4.2 dBFS にそろえました。各イベントの音量目安は再生時に適用してください。添付BGMは約2分41秒で、全体のピークが0 dBFSでした。BGMと重ねたときの最終的な聴感バランスは、再生側の音量調整後に確認してください。

## 再生成と試聴

```sh
python3 scripts/make_astera_sfx.py
```

7種類を順番に並べたプレビューは `docs/design/sound-effects/preview.wav` です。効果音の再生タイミング、連続再生の抑制、ON/OFF設定、マナーモード対応は、この素材制作タスクには含めていません。
