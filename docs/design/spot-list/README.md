# 8-14 おすすめ／要確認タブとスポット一覧

地図の直後に等幅の2タブを配置し、薄い白・細い銀色の縁・控えめな光で選択状態を表す。
背景は matchedGeometryEffect で移動し、視差効果を減らす設定ではアニメーションを止める。
上部の月・惑星が浮かぶ選択画面と確認操作は変更しない。下部ナビゲーションも追加しない。

## データと操作

- AppModel.predictions の判定・点数をそのまま使う。おすすめ＝recommended、要確認＝それ以外。
- 要確認内の「見えない見込み」「利用不可」は元のラベルを維持し、含まれることを注記する。
- 地点の種類による絞り込み後のデータを、タブの件数と表示行の両方に使う。
- 近い順は既存の LocationModel.distanceKm、スコア順は既存の totalScore を使う。
- 現在地がない場合は距離未取得と表示し、判定・スコア順に戻す。取得ボタン・許可拒否時の案内を用意する。
- 空の結果も表示し、要確認タブへの切り替えや絞り込み解除ができる。
- 詳細遷移は既存の String ID の NavigationLink、地図と日時・天体変更・更新操作を維持する。

## 写真とレイアウト

既存データに施設外観写真はないため、同梱された `far_<sceneId>.jpg` の周辺航空写真を再利用する。
地理院タイル等を元にした夜間色加工画像で、施設外観・実際の夜景写真として扱わない。
画像に「周辺航空写真」、一覧末尾に説明を付ける。画像がない場合は「写真なし」。
ImageIOで最大320pxへ縮小してから表示し、地面用4K画像の全展開を避ける。

写真92pt（一覧幅330pt未満は72pt）、本文は最低105ptで高さ方向へ折り返し、スコア・矢印は固定幅。
一覧幅280pt未満・アクセシビリティ文字サイズでは写真・スコアの下へ本文を回す。
名前は省略せず、説明は通常2行・アクセシビリティ文字サイズでは全文表示。
行に大きなカードの背景を付けず、細い水平線で区切る。

## 検証

- 静的確認：上部選択画面のソース一致、各Swiftファイル300行以内、既存地点データの再利用。
- Swift Testingを追加：全判定の2タブへの分配、件数、種類フィルター、距離未取得、スコア同点時の安定順。
- WindowsにSwift/Xcodeがないため、テスト実行・iOSビルド・シミュレータ描画は未実施。
- macOSで `cd Packages/StarCore && swift test`、`xcodebuild -scheme StarSpot -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build` を実行する。
- 実機で320/375/390pt、長い場所名、大きな文字、0件、現在地拒否、写真欠損、タブ移動、絞り込み解除、詳細遷移を確認する。
