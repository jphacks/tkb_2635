# 星座線データ

アプリ内の `App/Resources/Sky/constellations.json` は、[d3-celestial](https://github.com/ofrohn/d3-celestial) の星座線と日本語名を、実行時通信を使わないよう必要な項目だけに整形したデータです。線の座標は J2000 の星位置をもとにした GeoJSON 形式です。アプリは経度を赤経、緯度を赤緯として赤道座標に戻し、星図と同じ天球の向きに重ねます。

d3-celestial は星座線データの出典として IAU の星座図を挙げています。データとソフトウェアは BSD 3-Clause License で配布されているため、利用条件を `App/Resources/Sky/constellations-LICENSE.txt` に同梱し、画面の出典表示にも記載しています。外部のイラスト素材は含めていません。

これは無料の REST API ではなく、公開されている静的データです。アプリへの同梱により、通信環境や API キーに依存せず表示できます。

## ガラス調の見た目（b-1-3-4）

詳細画面の 3D（全体表示・観測者視点）と AR で、同じ見た目にそろえています。数字（太さ・濃さ・名札の数など）は `App/Views/ConstellationStyle.swift` と `ConstellationLabelPicker`（StarCore）に名前を付けてまとめています。

- 星座線: 細い明るい芯と、まわりの淡いにじみの二重。3D では星空の球より少し内側に置き、星の画像に隠れないようにしています（以前は球の外側にあり、観測者視点で見えていませんでした）
- つなぎ目の星: にじむ小さな光の点。明るい星（1.5 等以下）は少し大きくします
- 星座名: すりガラス風の小さな名札。見ている向きに近い星座から、明るい星を含む星座を優先して最大 6 個まで出し、近すぎる名札は出しません
- AR で建物にさえぎられている線・絵・名札は、消さずに薄く表示します

## 星座の線画（`App/Resources/Sky/constellation-art.json`）

オリオン座・はくちょう座・さそり座・わし座・おおぐま座・ふたご座・おうし座の 7 つに、星座の姿の線画を淡く重ねています。

**この線画はチームで作った簡略な線画で、実際の星座絵（既存の星図や画像）そのものではありません。** 外部の絵素材は、著作権を確認できないため使っていません。

- 形式: 星座ごとに、基準の星 2 つ（`anchors`、星の位置と絵の上の位置）と、折れ線（`strokes`、絵の平面の点）を持ちます。絵の平面は空を見上げたときの見た目（右が西、上が北、単位はおよそ度）です
- 置き方: 基準の 2 つの星が天球上の実際の位置に来るように、絵を拡大縮小・回転・移動して置きます（`ConstellationArt`、StarCore）。折れ線は滑らかな曲線にして描きます
- 入れなかった星座: こと座・しし座は、作った線画が見苦しかったため入れていません。カシオペヤ座は W 字の線だけで形が伝わり、人物の絵を簡略な線で作るのが難しいため入れていません
- 足し方: JSON に星座を 1 つ足すだけで表示されます（コードの変更は不要）。基準の星は `constellations.json` の線の星から選びます（テストで確かめています）

## 星座の姿の画像（PNG、b-1-3-5）

全 88 星座に、線画の代わりに、ガラス調の画像（`App/Resources/Sky/constellation-*.png`、透過 PNG）を重ねています。最初はオリオン座・はくちょう座・さそり座・わし座・おおぐま座・ふたご座の 6 つで、秋の 3 つ（b-1-3-6）と残りの 79（b-1-3-7）を順に足しました。

**この画像は、チームのメンバーが画像生成 AI（image_gen）で作ったもので、実際の星座絵や星図そのものではない簡略な絵です。** 天文学的に正確な姿や境界を表すものではありません。外部の絵素材は使っていません。

- 設定: `App/Resources/Sky/constellation-images.json`。星座ごとに、画像のファイル名と、基準点（恒星の位置と画像の画素の位置。画素は左上が原点で y が下向き）を持ちます。画素の位置は、素材の元の大きさ（1024×1024、`size`）で書きます。同梱する PNG は 512×512 に縮めていますが、画像は `size` の大きさに引き伸ばして貼るので、座標は変えなくてよいです画像に光る印が描き込まれている星には `"marked": true` を付け、アプリ側の星の光を重ねません（光が二重にならないように）
- 置き方（`ConstellationImage`、StarCore）: 基準点の星の中心で天球に接する平面へ画像を写します。基準点が 2 つなら拡大縮小・回転・移動だけ、3 つ以上なら基準点をすべて通るように画像をなめらかに変形します（薄板スプライン）。画像が折れ返る・大きすぎるなどの設定は読み込みません
- 基準点: 素材に付いていた光る印の対応（はくちょう座 6 点、ほか 2 点）に加え、2 点では体の向きが実際の星座線と合わなかったため、星座線の星と絵の部位（例: オリオンの右肩と足、さそりの頭と尾、おおぐまの鼻先・前足・後ろ足、ふたごの足）の対応を目で見て足しました。光る印の無い基準点は、画像の上で ±30px ほどの読み取りの幅があります
- おうし座: b-1-3-5 では、前の素材の牛が星座線と大きくずれたため入れませんでした。b-1-3-7 の新しい素材（アルデバランが顔、エルナトが角の先）では体が星座線に沿ったため、入れています
- 画像が読めないとき・設定がおかしいときは、その星座は自作の線画と線・名札に戻ります
- 見た目の数字（画像の濃さ `imageOpacity` = 0.5 など）は `ConstellationStyle.swift` にあります

### 秋の星座の追加（b-1-3-6）

カシオペヤ座・ペガスス座・アンドロメダ座の 3 つを足しました（同じく image_gen で作った 1024×1024 の透過 PNG、3 枚で約 1.3MB）。画像の光る印と星の対応は、素材と一緒に受け取った座標（読み取りの幅 ±4px）を使っています。

| 星座 | 基準点 | 置き方 |
|---|---|---|
| カシオペヤ座 | シェダル（胸元）・カフ（左手）の 2 点 | 拡大縮小・回転だけ。W 字の残りの 3 星は、絵の右手から外側に出ます |
| ペガスス座 | マルカブ（翼の付け根）・アルゲニブ（腰）の 2 点 | **素材の絵を左右反転して同梱**しています（下記） |
| アンドロメダ座 | アルフェラッツ（額）・ミラク（腰）・アルマク（足元）と、留め点 3 つ | 3 点だけで変形すると画像が大きく崩れたため、留め点を足しています（下記） |

- ペガスス座: 素材のままでは、実際の空と左右が逆向きで、首から鼻先（エニフ）への線が前脚に、前脚の線が頭に重なりました。左右反転すると、頭がエニフに、胴体が秋の四辺形に乗ります。反転は画素を並べ替えただけで、色や大きさは変えていません。前脚の線は、実際の空では背中側（翼の側）に伸びるため、絵の脚とは合いません
- アンドロメダ座: 額と足元の 2 点で置くと、腰の光る印が実際のミラクから約 3.5° ずれます。3 点で変形すると、画像の外側が大きく引き伸ばされ、幅の上限（90°）を超えて表示されませんでした。そこで、星座線の端の星 3 つ（光る印は無い）を、2 点で置いたときの画像上の位置に留め点として足し、腰の付近だけを動かしています。胴が少し縮みますが、腕の線が右腕に沿います
- 確認用の図（アプリと同じ置き方で画像を空の平面に貼り、星座線を重ねたもの。北が上、西が右。緑の丸が基準点）: [カシオペヤ座](autumn-cassiopeia.jpg)・[ペガスス座](autumn-pegasus.jpg)・[アンドロメダ座](autumn-andromeda.jpg)

### 全 88 星座の追加（b-1-3-7）

残りの 79 星座を足し、全 88 星座に画像が出るようにしました（同じく image_gen で作った透過 PNG。光る印の位置と星の対応は、素材と一緒に受け取った表を使っています）。

- 基準点: ほとんどが光る印 2 点（拡大縮小・回転だけ）。みなみじゅうじ座は 4 点、みなみのさんかく座・さんかく座は 3 点です。前からある 9 星座の設定は変えていません
- 画像の大きさ: 88 枚をそのまま入れると、3D で画像ごとに 2 枚のテクスチャ（色と透明度）を作るため、メモリを多く使います。そこで全 88 枚を 512×512 に縮めて同梱しています（88 枚で約 15MB）
- うみへび座: 画像の幅が空の上で約 93° あり、前の上限（90°）を超えて表示されなかったため、上限を 100° にしました（`ConstellationImagePlacement.maximumSpan`）
- へび座: 星座線のデータが頭と尾の 2 行に分かれているため、テストでは両方の行の星を見るようにしました（素材は蛇だけの絵で、へびつかい座の人物とは別の画像です）
- 合い方: 基準点 2 点で置いているので、基準点以外の星は絵とずれることがあります（例: りゅうこつ座・とも座・うお座・うさぎ座は、星座線が絵の外にはみ出します）。ずれが大きくて直したい星座は、基準点を足して調整します
- 確認用の図（アプリと同じ置き方で、画像に星座線（水色）と基準点（緑の丸）を重ねたもの）: [1](all-88-check-1.jpg)・[2](all-88-check-2.jpg)・[3](all-88-check-3.jpg)・[4](all-88-check-4.jpg)。前からある 9 星座は、図では素材の元の基準点で描いているため、アプリの見た目と違います
- シミュレータでの見た目（新宿中央公園、10/25 21:00）: [all-88-simulator.jpg](all-88-simulator.jpg)
