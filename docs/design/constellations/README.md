# 星座線データ

アプリ内の `App/Resources/Sky/constellations.json` は、[d3-celestial](https://github.com/ofrohn/d3-celestial) の星座線と日本語名を、実行時通信を使わないよう必要な項目だけに整形したデータです。線の座標は J2000 の星位置をもとにした GeoJSON 形式です。アプリは経度を赤経、緯度を赤緯として赤道座標に戻し、星図と同じ天球の向きに重ねます。

d3-celestial は星座線データの出典として IAU の星座図を挙げています。データとソフトウェアは BSD 3-Clause License で配布されているため、利用条件を `App/Resources/Sky/constellations-LICENSE.txt` に同梱し、画面の出典表示にも記載しています。外部のイラスト素材は含めていません。

これは無料の REST API ではなく、公開されている静的データです。アプリへの同梱により、通信環境や API キーに依存せず表示できます。

## ガラス調の見た目（b-1-3-4）

詳細画面の 3D（全体表示・観測者視点）と AR で、同じ見た目にそろえています。数字（太さ・濃さ・名札の数など）は `App/Views/ConstellationStyle.swift` と `ConstellationLabelPicker`（StarCore）に名前を付けてまとめています。

- 星座線: 細い明るい芯と、まわりの淡いにじみの二重。3D では星空の球より少し内側に置き、星の画像に隠れないようにしています（以前は球の外側にあり、観測者視点で見えていませんでした）
- つなぎ目の星: にじむ小さな光の点。明るい星（1.5 等以下）は少し大きくします
- 星座名: すりガラス風の小さな名札。見ている向きに近い星座から、明るい星を含む星座を優先して最大 6 個まで出し、近すぎる名札は出しません
- AR で建物にさえぎられている線・絵・名札は、消さずに薄く表示します

## 星座の線画（`App/Resources/Sky/constellation-art.json`）

オリオン座・はくちょう座・さそり座・わし座・おおぐま座・ふたご座・おうし座の 7 つに、星座の姿の線画を淡く重ねています。

**この線画はチームで作った簡略な線画で、実際の星座絵（既存の星図や画像）そのものではありません。** 外部の絵素材は、著作権を確認できないため使っていません。

- 形式: 星座ごとに、基準の星 2 つ（`anchors`、星の位置と絵の上の位置）と、折れ線（`strokes`、絵の平面の点）を持ちます。絵の平面は空を見上げたときの見た目（右が西、上が北、単位はおよそ度）です
- 置き方: 基準の 2 つの星が天球上の実際の位置に来るように、絵を拡大縮小・回転・移動して置きます（`ConstellationArt`、StarCore）。折れ線は滑らかな曲線にして描きます
- 入れなかった星座: こと座・しし座は、作った線画が見苦しかったため入れていません。カシオペヤ座は W 字の線だけで形が伝わり、人物の絵を簡略な線で作るのが難しいため入れていません
- 足し方: JSON に星座を 1 つ足すだけで表示されます（コードの変更は不要）。基準の星は `constellations.json` の線の星から選びます（テストで確かめています）
