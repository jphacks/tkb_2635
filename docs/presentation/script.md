# 発表の台本（90秒・スライド2枚）

スライドは [index.html](index.html) をブラウザで開く。→ / Space / クリックで次、← で前、F で全画面、N で台本を表示。

数字は 2026-10-24 21:00 の計算値（スライドの3D画面と同じ時刻）。月は南南東・高さ 57.6°、渋谷駅東口 地上の遮蔽仰角 73.9°、SHIBUYA SKY は 0°（目の高さの差 229 m）。

## 1枚目　課題（0:00〜0:45）

東京では、天気が良くても、月や星が見えないことがあります。原因はビルです。
10月24日の夜9時、月は南南東の空、高さ58度にあります。ところが渋谷駅の東口では、その方角のビルが74度の高さまで空をふさぎ、月は隠れてしまいます。
同じ時刻、229メートル高いSHIBUYA SKYでは、さえぎるものがなく、月が見えます。
見えるかどうかは、天気だけでなく、どの高さから見るかで決まります。

## 2枚目　解き方（0:45〜1:30）

Asteraは、この判定を23区の43地点でまとめて行います。
観測する人の目の高さ、PLATEAUの3D都市モデル、月・惑星・恒星の位置、そして雲や街明かりを組み合わせ、方位1度ごとに、空がどこまで開けているかを計算します。
その結果を、理由の文と3Dで示し、今夜行く場所を推薦します。
使うのは公開データだけなので、ほかの地点や都市にも広げられます。
