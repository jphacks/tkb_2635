# 発表の台本（90秒・スライド1枚）

スライドは [index.html](index.html) をブラウザで開く。F で全画面、N で台本を表示。

数字は 2026-10-24 21:00 の計算値。月は南南東・高さ 57.6°、渋谷駅東口 地上の遮蔽仰角 73.9°（月は隠れる）、SHIBUYA SKY は 0°（目の高さの差 229 m、月は見える）。

## 台本

東京では、天気が良くても、ビルに隠れて月や星が見えないことがあります。
たとえば10月24日の夜9時、渋谷駅の東口では月がビルに隠れますが、229メートル高いSHIBUYA SKYからは見えます。見えるかどうかは、どの高さから見るかで決まります。

Asteraは、この判定を23区の43地点でまとめて行うiPhoneアプリです。
観測する人の目の高さ、PLATEAUの3D都市モデル、月・惑星・恒星の位置、そして雲や街明かりを組み合わせ、方位1度ごとに、空がどこまで開けているかを計算します。
その結果を、理由の文と3Dで示し、今夜行く場所を推薦します。
使うのは公開データだけなので、ほかの地点や都市にも広げられます。
