# 天体の位置計算の検証（3-03）

アプリの天体計算（`Packages/StarCore/Sources/StarCore/Astro/Astro.swift`）が、どれくらい正しいかを、精密な天文計算ソフトと見比べた記録。

## 結論

- **月の高度・方位の差は 1° 以内**（高度の差は最大 0.37°、方位の差は空の上での距離で最大 0.36°）。3-03 の完了条件を満たす
- 月の輝面比（光って見える割合）の差は最大 0.002、太陽の位置の差は最大 0.007°
- 恒星は最大 0.37° ずれる。歳差（地球の自転軸がゆっくり首ふりする動き。2000 年からの 26 年で約 0.37°）を補正していないのが主な原因で、3-06 で直す

## 比較の相手と方法

| 項目 | 内容 |
|---|---|
| 比較相手 | [skyfield](https://rhodesmill.org/skyfield/) 1.55 + NASA JPL の天体暦 DE421（研究にも使われる精密な位置計算） |
| 観測地点 | 渋谷駅東口（35.658, 139.702816）、葛西臨海公園（35.643, 139.861）。標高 0 m |
| 日時 | 2026-10-24 00:00 〜 2026-11-30 18:00（UTC）を 6 時間ごと。2 地点 × 152 時刻 = 304 件 |
| 天体 | 月・太陽、恒星 6 つ（ベガ・シリウス・アークトゥルス・北極星・アンタレス・デネブ） |
| 位置の条件 | 観測地点から見た見かけの位置。大気差（空気で光が曲がり、少し高く見える分）を含む。気温 10°C・気圧 1013 hPa |
| 恒星の座標 | `StarCatalog.swift` の J2000.0 の値をスクリプトが読み取り、同じ値を skyfield に渡す |
| 誤差の測り方 | 2 つの位置の角距離（空の上での離れ具合）。月は高度の差、方位の差（方位差 × cos 高度）も別に見る |

位置の比較は、参照値で**地平線より上にある件だけ**を対象にした。地平線の約 1° 下で大気差の計算を打ち切る位置が、アプリと skyfield でわずかに違い、そこで最大 0.7° の段差が出るため。地平線より下の天体はアプリでは「見えない」扱いなので、この差は推薦に影響しない（打ち切りより上では、両者の大気差の差は 0.01° 未満）。

## 結果（2026-10-24 時点のコード）

| 天体 | 比べた件数 | 最大誤差 | 平均誤差 | テストの許容 |
|---|---:|---:|---:|---:|
| 月（位置） | 156 | 0.369° | 0.145° | 0.5° |
| 月（高度の差） | 156 | 0.368° | 0.099° | 1° |
| 月（方位の差、空の上での距離） | 156 | 0.364° | 0.083° | 1° |
| 月（輝面比） | 304 | 0.0016 | 0.0006 | 0.01 |
| 太陽 | 152 | 0.007° | 0.006° | 0.1° |
| アンタレス | 140 | 0.369° | 0.366° | 0.5° |
| アークトゥルス | 174 | 0.320° | 0.316° | 0.5° |
| シリウス | 105 | 0.293° | 0.288° | 0.5° |
| デネブ | 238 | 0.189° | 0.187° | 0.5° |
| ベガ | 228 | 0.174° | 0.173° | 0.5° |
| 北極星 | 304 | 0.159° | 0.158° | 0.5° |

- 月の方位の数字そのものの差は最大 1.78° だが、これは月が高度 78°（ほぼ真上）にあったとき。真上の近くでは方位 1° が空の上では短い距離にしかならない（このときの空の上での距離は 0.36°）
- 月の誤差は、アプリが使う低精度式（主な項だけの式）によるもの。建物の見え方の判定（判定の余裕 δ = 1°）には十分
- 恒星の誤差は、天体ごとにほぼ一定（平均と最大がほぼ同じ）。時刻によらず決まった方向にずれる、歳差の特徴と合う

## 恒星の誤差と今後

恒星は J2000.0（2000 年）の座標をそのまま使っており、歳差を補正していない。2026 年では最大 0.37° ずれる。3-06 で歳差補正を入れ、許容を 0.1° に下げる予定。

## もう一度確かめる手順

```bash
python3 -m pip install skyfield
python3 scripts/verify_astro.py        # 参照値を作り直す（天体暦 de421.bsp は初回に ~/.cache/skyfield へ取得）
cd Packages/StarCore && swift test --filter AstroReferenceTests
```

- 参照値は `Packages/StarCore/Tests/StarCoreTests/Fixtures/astro_reference.json`（約 144 KB）。先頭の `meta` に出典・生成日時・天体暦の名前がある
- テストを実行すると、天体ごとの最大・平均誤差が出力に表示される。上の表はその値
- 天体暦の置き場所は環境変数 `SKYFIELD_DATA` で変えられる
