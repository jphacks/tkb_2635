# 観測地点をさらに7か所追加（追加タスク f・関連 1-10）

確認日: 2026-10-24。これで観測地点は計19か所。まだ地点が無かった区（練馬・北・江東・港・中央・大田）と、海沿いの公園を優先した。

- 常時開園の4か所は `lastVerifiedAt` を 2026-10-24 にした。未確認の3か所は 1-06 の荒川河川敷と同じ形（`openingHours.alwaysOpen: false`、`accessRules.unverified: true`、`lastVerifiedAt: null`）にし、画面では「入場可否は未確認」「要確認」と出る。
- 若洲海浜公園は、海釣り施設（6:00〜21:00）の位置を地図で確定できなかったため今回は見送った。

## 数値の出どころ

| 項目 | 入れた値 | 出どころ |
|---|---|---|
| 緯度・経度 | 園内の代表点 | 地理院地図で園内を確かめ、国土地理院の逆ジオコーダで町名が公式の所在地と合うことを確認。浮間公園は国土地理院の地名検索の代表点 |
| 床面標高 | 0.9〜38.9 m | 国土地理院の標高API（1m（レーザ））。応答は[保存記録](more-parks-evidence.json)にある |
| 目線高さ | 1.6 m | 想定値 |
| 地平線仰角（暫定） | 5〜12° | 地理院地図で見た周りの建物・樹木・高架から置いた暫定値。根拠は各地点の `memo` に書いた |
| 地域の光害 | 0.57〜0.76 | VIIRS 2025 年の年次合成から `scripts/viirs_to_spots.py` と同じ計算で出した（[記録](../data/viirs-light-index.json)） |
| 近傍照明 | null | 未確認（6-04 の机上評価は別作業） |

VIIRS の値は新しい7か所だけに入れた。`--write` をそのまま実行すると 1-10 の3か所（舎人・水元・駒沢、今は null）も書き換わるため。3か所の値（0.69・0.54・0.65）は確認表には出るが、反映は別の作業とする。
