# 6-04 近くの照明（近傍照明）の段階評価

担当: ミスミ。記録日: 2026-10-24。

`spots.json` の `localGlareLevel`（近くの照明、0〜3）を、地点ごとに決める。地域全体の明るさ（`regionalLightIndex`、[6-03](../data/viirs-light-index.md)）とは別に、「その場所に立ったとき、目に入る照明がどれくらいあるか」を表す。照度計で測った値ではない。

## 0〜3 の定義

| 段階 | 目安 |
|---|---|
| 0 | 視界内に照明がない |
| 1 | 遠くに街灯・建物の明かりがあるだけ |
| 2 | 周囲に街灯や看板があり、足元が明るい |
| 3 | 直射光や室内照明が目に入る（展望室のガラスへの映り込みを含む） |

迷ったら明るいほう（数字が大きいほう）にする。暗さを甘く見積もって「見える」と言いすぎないため。

## 机上評価（desk）と現地確認（onsite）

| `method` | 意味 | アプリの表示 |
|---|---|---|
| `desk` | 公式サイトの写真・案内文や、Google マップの夜の写真を見て決めた | 「近傍照明（机上評価 YYYY-MM-DD）」。推薦理由に「現地未確認」と出る |
| `onsite` | 夜に現地へ行き、観測する位置に立って確かめた | 「近傍照明（現地確認 YYYY-MM-DD）」 |

今は全地点が `desk`（現地に行けていない）。現地で確かめたら `onsite` に書き換える。

## 評価のやり方（机上評価）

1. 公式サイト（`spots.json` の `officialWebsite` など）で、夜景写真や夜の照明の案内を探す
2. Google マップで地点名を検索し、「写真」から夜（または日没後）の写真を探す。登録地点に近い場所の写真を選ぶ
3. 見えたものだけを根拠に、上の定義で 0〜3 を決める。写っていないこと・場所が違うかもしれないことを、推測で埋めない
4. 根拠が見つからなければ `level` を `null` のままにし、`note` に「夜の写真が見つからなかった」などと書く
5. [assessments.json](assessments.json) に書く

Google マップの写真の URL は長く、変わりやすい。`sources` には検索の URL（`https://www.google.com/maps/search/?api=1&query=...`）を入れ、どの写真を見たか（撮影年月、写っていたもの）を `note` に書く。投稿者の名前は書かない。

### assessments.json の形

```json
{
  "地点 id": {
    "level": 2,
    "method": "desk",
    "checkedAt": "2026-10-24",
    "sources": ["見たページの URL"],
    "note": "何を見てそう判断したか 1〜2 文"
  }
}
```

- `level`: 0〜3、または `null`（根拠なし）
- `method`: `"desk"` または `"onsite"`
- `checkedAt`: 確かめた日（YYYY-MM-DD）

## spots.json への反映

```bash
python3 scripts/apply_lighting_check.py            # 変わる内容を表で見るだけ（既定）
python3 scripts/apply_lighting_check.py --write    # spots.json を書き換える
```

- `level` がある地点だけ、`localGlareLevel`・`lightingCheckDate`・`lightingCheckMethod` を書き換える
- `level` が `null` の地点は触らない（アプリでは「未確認」のまま）
- キーの順を保ち、今までと同じ整形で書くので、差分は 3 行ずつになる

## 再評価の手順

1. 新しい写真や現地確認の結果をもとに、`assessments.json` の該当地点を直す（`checkedAt` を更新し、`sources` と `note` も書き直す）
2. `--dry-run` で変わる内容を確かめてから `--write` する
3. `python3 -m pytest scripts/tests` と `cd Packages/StarCore && swift test` を通し、PR を出す

`level` を `null` に戻しても、反映済みの `spots.json` の値は消えない（触らないため）。消したいときは `spots.json` から 3 項目を手で消す。
