# 2-02 渋谷駅周辺のPLATEAU原本を取得

取得日: 2026-10-24。担当: Codex。

## 対象と出典

- データ名: 3D都市モデル（Project PLATEAU）渋谷区（2025年度）
- 提供元: 東京都。配信: 国土交通省 Project PLATEAU。
- [G空間情報センター](https://www.geospatial.jp/ckan/dataset/plateau-13113-shibuya-ku-2025)
- [公式配信APIの説明](https://docs.plateauview.mlit.go.jp/datasets/citygml/)
- [検索結果API](https://api.plateauview.mlit.go.jp/datacatalog/citygml/r:139.695,35.652,139.707,35.665)
- 標準製品仕様書: 第5.0版。ファイル形式: CityGML 2.0。
- 原本READMEの作成年月日: 2026-03-13（2025年度版）。

渋谷駅とSHIBUYA SKYの周囲約500mを覆うよう、経度139.695〜139.707・緯度35.652〜35.665に交差する建物メッシュを検索した。検索には隣接区も返るため、自治体コード13113（渋谷区）だけを選択した。対象は53393585・53393586・53393595・53393596の4区画。周囲500mで切り抜いたデータではなく、区画単位の原本である。

## 入手したもの

- 建物CityGML 4ファイル（LOD1、部分的にLOD2を含む）
- 道路CityGML 4ファイル（`udx/tran/`、4-09 で追加。3D の街灯の位置と路面の明るさだけに使う）
- コードリストZIP（用途などの属性コードの意味）
- メタデータZIP（原典・仕様）
- 補足資料ZIP（公式README・索引図）

`plateau-shibuya-2025.json` に取得URL、バイト数、SHA-256、検証結果を記録している。原本は大きいためGitには含めない。

## 再取得

リポジトリのルートでPython 3を使う（追加パッケージ不要）。保存先はリポジトリの外を指定する。

```bash
python3 scripts/download_plateau.py --output ../outputs/plateau-shibuya-2025
```

同じファイルがあればSHA-256で検証して再利用し、不一致なら再取得する。ダウンロード途中のファイルは `.part` とし、サイズとSHA-256が一致してから正式な名前にする。ネットワークエラー時は再実行する。

## 検証結果

- 建物CityGML 4ファイルを最後までXMLとして読み込み、計9,535棟を確認。全棟に `measuredHeight` と `lod1Solid` がある。うち3,064棟に `lod2Solid` がある。
- 座標参照系はEPSG:6697。建物数とLOD別件数はAPIの目録と一致。
- 建物原本は計364,026,814バイト。APIの `fileSize` と実際のバイト数には差があるため、両方を目録に保存した。再取得の照合には実際のバイト数と取得時に計算したSHA-256を使う。
- 補足ZIP 3ファイルは全エントリのCRC検査に成功。SHA-256は配布元が公開した照合値ではなく、今回取得したファイルの再現用の値。
- 再取得スクリプトを取得済み11ファイル（4-09 で道路4ファイルを追加）に対して実行し、全て一致・再利用できることを確認。
- アプリのコードは変えていないため、Swiftテスト・iOSビルドは今回未実施。
