# 2-04 渋谷シーンへのPLATEAU導入

導入日: 2026-10-24。担当: Codex。

## 置き換えたもの

渋谷シーンの手作りの13棟を、渋谷駅付近の原点（35.6580, 139.7016）から半径500mにかかるPLATEAU由来の1,497棟に置換した。西新宿の8棟と渋谷以外の観測地点は変更していない。アプリの詳細画面で、収録建物数と原典・近似の注意を確認できる。

## 原典・利用条件

- 東京都「3D都市モデル（Project PLATEAU）渋谷区（2025年度）」
- [配布元](https://www.geospatial.jp/ckan/dataset/plateau-13113-shibuya-ku-2025)
- 原本: メッシュ53393585 / 53393586 / 53393595 / 53393596の建物CityGML（標準製品仕様書5.0、EPSG:6697）
- [原本取得記録](plateau-shibuya-2025.md)、[URL・SHA-256](plateau-shibuya-2025.json)
- 原本READMEが認めるCC BY 4.0で利用。出典と「加工してAsteraチームが作成」をREADMEとシーンのsourceに記載し、画面にも表示する。

## 変換・再現

[2-03のコマンド](plateau-converter.md)で4区画の原本を変換する。基準標高15m・半径500m・原点35.6580/139.7016を使用する。1,497棟の出力を既存の `buildings.json` の `id == "shibuya"` の要素だけに置き、sourceには本記録の出典・加工表示・暫定値の注意を入れる。西新宿の要素は保持する。

- 座標・形状・高さ・用途は変換結果と全棟一致。個々の建物をデモに合わせて移動・拡大していない。
- 地盤標高と計測高さ、LOD1屋根標高から高い方の屋根を採用し、シーン地面15mからの有効高さへ変換。
- 計測高さが不明な47棟はLOD1形状を使用。0mの建物として扱わない。
- 長方形と半径500mの円が交差する場合に採用。建物全体は切り取らない。
- 入力SHA-256、採用数、建物IDと高さの根拠、代表地点の座標は [導入目録](shibuya-scene-integration.json) に保存。

## 観測地点と建物の対応

### SHIBUYA SKY

旧 `hostBuildingId: scramble_square` を原本の `bldg_7b006717-e9e6-4a94-8843-1f4ce13b2509` に対応させた。原本のbuildingIDは `13113-bldg-375`。渋谷駅東側の位置・周囲の駅舎との関係・高層建物であることから照合したもので、原本のgml:nameに施設名が明記されているわけではない。

- 参考: [施設公式アクセス](https://www.shibuya-scramble-square.com/access/)（渋谷二丁目24番12号・駅直結／直上）
- 参考: [施設公式資料](https://www.shibuya-scramble-square.com/assets/pdf/about/20250325scsq.pdf)（東棟約229.7m）。公式の建物高さは標高ではなく、PLATEAUの計測高さ220mとも差がある。高さを一致させるための補正はしていない。
- 屋上マーカーは建物の外接矩形中心を使い、35.658384 / 139.702242へ変更。実際の立ち位置の測量値ではない。
- 原本の地盤標高14.6m、屋根標高234.6m。基準標高15mからの有効高さは219.6m。
- 地点の床面標高244m・目線1.5mは既存の暫定値を保持。モデルの屋根より観測者の目が10.9m高く表示される。現地の観測面標高とは未照合で、1-07で確認する必要がある。この注意は地点のmemoにも表示する。

### 地上のデモ地点

旧35.657638 / 139.702816は、導入した建物の外接矩形の内側に重なっていた。地上観測者を建物内に置かないため、約40m北の35.658000 / 139.702816へ調整した。新しい位置が全ての収録建物の外接矩形の外側にあることをテストしている。

この位置はデモ用の代表点であり、公道・歩行空間・夜間立入可否を現地で確認したものではない。床面標高15mも暫定値。地点のmemoで未確認と明示した。施設の営業時間・料金・施設情報の最終確認日は変更していない。

## 検証

- JSONをStarCoreの型で読み込み、1,497棟のID重複なし・有限かつ正の寸法・指定範囲への交差を確認。
- 屋上マーカーがhostBuildingIdの建物内、地上マーカーが全建物の外側にあることを確認。
- 実データで建物IDによる遮蔽除外が働くことを確認。
- 既存の2026-10-24 21:00 JSTの月のテストで、地上では遮蔽・屋上では可視という判定と開放度の差を維持。
- `swift test --disable-sandbox` 25件成功（既存22件＋導入データの3件）。
- 変換結果と同梱した全建物の一致、西新宿と渋谷以外の地点が変更されていないことも別途照合。
- iOSビルドはパッケージ解決時の `sandbox_apply: Operation not permitted` で実行できず、シミュレータの3D表示・描画性能・スクリーンショットは未確認。

## 制約

外接直方体による近似のため、凹凸・建物内の隙間・窓・地形は再現しない。原点から500m外にある高層建物は含まれない。原本が現況と異なる場合もある。デモとしての座標整合性と現地での観測精度を混同せず、1-07・4-04・9-04などで別途確認する。
